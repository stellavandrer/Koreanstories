Intonation avancée A2

Prononciation +8 XP

Maîtrisez les patterns d'intonation qui donnent un accent naturel.

Règle 1 : La montée finale pour les questions

Les questions en coréen se distinguent principalement par l'intonation montante sur la dernière syllabe.

가요.
↘ descend → affirmatif
Je/Il va.
가요?
↗ monte → question
Vous allez ?
Même phrase, même mots — seule l'intonation change le sens !

Règle 2 : L'emphase par allongement

Pour insister, les Coréens allongent la voyelle de la syllabe à accentuer.

진짜 → 진~짜 (vrai-ment !)
Normale vs insistante
너무 → 너~무 (tellement !)
Forte émotion
En K-pop et dans les dramas, vous entendrez souvent ce procédé pour l'expression émotionnelle.

Règle 3 : Liaison entre syllabes

Quand une consonne finale précède une voyelle, elle se prononce avec la syllabe suivante.

Écrit
먹어요
meo-geo-yo
Prononcé
머거요
meo-geo-yo (⟨k⟩ → ⟨g⟩)
학원 : hag-won → [ha-gwon]
있어요 : iss-eo-yo → [i-sseo-yo]
읽어요 : ilg-eo-yo → [il-geo-yo]
Cette règle s'applique automatiquement — votre oreille s'y habitue rapidement !

Règle 4 : Intonation émotionnelle

Le coréen utilise des patterns d'intonation distincts selon l'émotion.

정말요?! → voix qui monte + pause
왜요~ → voix basse et allongée
어머! → courte, pointue, montante
그냥요… → plate, légère descente

Exercices pratiques

Lisez ces phrases à voix haute en appliquant les règles :

오늘 뭐 먹었어요?
↗ Question → montée finale sur 요?
진~짜 맛있어요!
Allongement de 짜 pour insister
밥을 먹었어요. (=meo-geo-sseo-yo)
Liaison : 먹 + 었 → meo-geo
한국어 너~무 재미있어요!
Allongement + liaison + enthousiasme
