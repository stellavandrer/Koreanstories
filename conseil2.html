La règle mnémotechnique
Sino-coréen (일·이·삼...) — Pour tout ce qui vient de Chine : les dates, l'argent, les mathématiques, les étages, les minutes, les numéros de téléphone.

Natif coréen (하나·둘·셋...) — Pour les choses "humaines" : l'âge, les heures, les objets qu'on tient et qu'on compte, les bouteilles, les personnes.
