Les verbes d'habillage — chaque vêtement son verbe !

En coréen, on n'utilise pas le même verbe selon ce qu'on met :
👉 입다 — pour les vêtements qui couvrent le corps (haut, bas, robe)
👉 신다 — pour les chaussures et chaussettes
👉 쓰다 — pour les chapeaux et lunettes
👉 끼다 — pour les gants, bagues, lunettes
👉 차다 — pour les montres, ceintures
👉 메다 — pour les sacs à dos
👉 들다 — pour les sacs à main
티셔츠를 입어요.
Je mets un t-shirt.
운동화를 신어요.
Je mets des baskets.
모자를 써요.
Je mets une casquette.
시계를 차요.
Je mets une montre.
가방을 들고 가요.
Je vais avec un sac à la main.

Scénario — Dans un magasin à Myeongdong

Dialogue type
직원 : 어서 오세요! 뭐 찾으세요?
Vendeur : Bienvenue ! Vous cherchez quelque chose ?
나 : 검은색 자켓을 찾고 있어요.
Moi : Je cherche une veste noire.
직원 : 이건 어떠세요? 사이즈 M 있어요.
Vendeur : Que dites-vous de celle-ci ? Il y a une taille M.
나 : 입어 봐도 돼요?
Moi : Je peux l'essayer ?
직원 : 네, 탈의실은 저쪽이에요.
Vendeur : Oui, la cabine d'essayage est là-bas.
나 : 잘 어울려요? 얼마예요?
Moi : Ça me va bien ? Combien ça coûte ?
