Comment marche un clavier coréen ?

Contrairement au français, on ne tape pas des lettres « finies » : on tape des jamo (consonnes et voyelles) et le système compose les syllabes tout seul :

ㅎ + ㅏ + ㄴ = 한
ㄱ + ㅣ + ㅁ + ㅊ + ㅣ = 김치

Le layout standard s'appelle 2-beolsik (두벌식) : consonnes à gauche, voyelles à droite. La touche Maj donne les doubles consonnes (ㄲ ㄸ ㅃ ㅆ ㅉ).

Activer le clavier coréen

iPhone / iPad2 minRéglages → Général → Clavier → Claviers → Ajouter… → Coréen (standard). Ensuite, le bouton de langue du clavier bascule entre français et coréen.
Android (Gboard)2 minParamètres → Système → Langues et saisie → Gboard → Langues → Ajouter → Coréen. Choisis le layout « 2-Bulsik » (standard). Astuce : Samsung Keyboard propose aussi le coréen nativement.
Windows3 minParamètres → Heure et langue → Langue → Ajouter le coréen (Microsoft IME). La touche Alt droite (한/영) bascule hangeul/latin. Pas besoin d'acheter de stickers clavier : tes doigts apprendront les positions.
Mac2 minRéglages Système → Clavier → Sources de saisie → + → Coréen → 2-Set Korean. Bascule rapide : Ctrl + Espace (ou la touche de langue dédiée).
