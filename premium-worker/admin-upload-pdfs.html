Upload des fiches PDF Premium vers KV

Outil interne à usage unique — envoie les fichiers PDF ou les fragments HTML du dossier pdf/ vers le stockage KV du Worker, pour qu'ils ne soient plus jamais servis en clair. Aucune installation nécessaire, tout se passe dans ce navigateur.

Une fois tous les fichiers envoyés (visible dans le journal ci-dessous), retourne dans Cloudflare → Worker ks-premium → Settings → Variables and Secrets, et supprime ADMIN_UPLOAD_TOKEN pour désactiver cet outil définitivement.
