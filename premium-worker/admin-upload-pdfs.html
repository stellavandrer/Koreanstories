Envoi des fichiers vendus

Outil interne : envoie les fichiers payants vers le stockage du Worker, pour qu'ils ne soient jamais servis en clair depuis le site. Aucune installation, tout se passe dans ce navigateur.

Livret A1 (gros fichier → R2)

Le livret pèse 53 Mo en 200 dpi. KV plafonne à 25 Mo par valeur — c'est cette limite qui l'obligeait à sortir en 120 dpi, visiblement pixelisé. Il part donc sur R2, qui n'a pas cette contrainte.

Le nom du fichier sur ton disque n'a aucune importance ici : quel qu'il soit, il sera enregistré sous livret-a1, le nom que la page de vente réclame. C'est exactement le piège qui avait causé un « livret introuvable » le 6 août — un fichier nommé livret-a1-koreanstories.pdf arrivait sous une clé que personne ne cherchait.

Les 35 fiches Premium (petits fichiers → KV)

Inchangé : chaque fiche fait quelques centaines de Ko et reste dans KV. Ici le nom du fichier compte — il devient la clé de stockage.

Une fois tous les fichiers envoyés, retourne dans Cloudflare → Worker ks-premium → Settings → Variables and Secrets, et supprime ADMIN_UPLOAD_TOKEN pour désactiver cet outil définitivement.
