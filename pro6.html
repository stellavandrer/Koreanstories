Liaisons & changements

Sonner naturel : les 4 règles fondamentales

A2 · Prononciation +10 XP

L'écriture coréenne et sa prononciation ne coïncident pas toujours. Quatre règles expliquent pourquoi 한국어 se dit [한구거] et pas [한국어]. Maîtrise-les pour comprendre les natifs.

1. 연음 — Liaison consonantique

1연음 (yeon-eum)
Quand une consonne finale (받침) est suivie d'une voyelle, elle glisse vers la syllabe suivante.
한국어 → [한구거]
한국 (Corée) + 어 (langue) : le ㄱ de 국 se prononce dans la syllabe 어.
음악 → [으막]
음 + 악 : le ㅁ glisse vers la voyelle suivante.
옷이 → [오시]
옷 (vêtement) + 이 (particule sujet) : ㅅ devient initiale de la syllabe finale.
읽어요 → [일거요]
Quand il y a deux consonnes finales (ㄺ), la deuxième passe à la syllabe suivante.
Astuce : la liaison s'entend surtout devant les particules (은/는, 이/가, 을/를, 에) et les terminaisons verbales (-아요/어요).

2. 격음화 — Aspiration

2격음화 (gyeok-eum-hwa)
Quand une consonne (ㄱ ㄷ ㅂ ㅈ) rencontre ㅎ, elles fusionnent en consonne aspirée (ㅋ ㅌ ㅍ ㅊ).
좋다 → [조타]
ㅎ + ㄷ → ㅌ : être bon / aimer.
많다 → [만타]
ㄶ + ㄷ → ㄴ + ㅌ : être nombreux.
축하해요 → [추카해요]
ㄱ + ㅎ → ㅋ : félicitations !
좋아해요 → [조아해요]
Exception : ㅎ devant voyelle disparaît (pas d'aspiration ici).
Mémo : ㄱㄷㅂㅈ + ㅎ donnent leur équivalent aspiré ㅋㅌㅍㅊ. Pense « + souffle d'air ».

3. 경음화 — Tensification

3경음화 (gyeong-eum-hwa)
Après certaines consonnes finales (ㄱ ㄷ ㅂ), les consonnes ㄱ ㄷ ㅂ ㅅ ㅈ qui suivent deviennent tendues (ㄲ ㄸ ㅃ ㅆ ㅉ).
학교 → [학꾜]
ㄱ + ㄱ → ㄱ + ㄲ : école.
식당 → [식땅]
ㄱ + ㄷ → ㄱ + ㄸ : restaurant.
늦잠 → [늗짬]
ㅈ devient ㅉ : faire la grasse matinée.
입국 → [입꾹]
ㅂ + ㄱ → ㅂ + ㄲ : entrée dans le pays.
Ressenti : la tensification donne une attaque sèche, comme un petit « coup » de glotte sur la consonne.

4. 비음화 — Nasalisation

4비음화 (bi-eum-hwa)
Quand ㄱ ㄷ ㅂ sont suivis de ㄴ ou ㅁ, ils deviennent leur équivalent nasal (ㅇ ㄴ ㅁ).
국물 → [궁물]
ㄱ + ㅁ → ㅇ + ㅁ : bouillon, soupe.
한국말 → [한궁말]
ㄱ devient ㅇ devant ㅁ : la langue coréenne.
입니다 → [임니다]
ㅂ + ㄴ → ㅁ + ㄴ : c'est… (terminaison formelle).
받는 → [반는]
ㄷ devient ㄴ devant ㄴ : qui reçoit.
Truc : chaque consonne devient le nasal de sa famille → ㄱ→ㅇ, ㄷ→ㄴ, ㅂ→ㅁ.
