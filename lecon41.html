Conjugaison coréenne — Les 3 temps
Présent — -아요 / -어요
Terminaison : dernière voyelle de la racine = ㅏ/ㅗ → -아요, sinon → -어요
Ex. 가다 → 가아요 = 가요 · 먹다 → 먹어요
Passé — -았어요 / -었어요
Même règle vocale + 았/었 + 어요
Ex. 가다 → 갔어요 · 먹다 → 먹었어요 · 하다 → 했어요
Futur — -(으)ㄹ 거예요
Racine + ㄹ/을 거예요. Si racine finit par voyelle → -ㄹ 거예요, sinon → -을 거예요
Ex. 가다 → 갈 거예요 · 먹다 → 먹을 거예요
하다 verbes (공부하다, 일하다…) : présent 해요, passé 했어요, futur 할 거예요 — toujours!
